# 🎯 Oráculo de Loterias - Dashboard

Este branch contém os arquivos HTML estáticos do dashboard interativo.

## 📊 Conteúdo

- `index.html` - Dashboard principal com análises de todos os jogos
- `styles.css` - Estilos e tema do dashboard
- Arquivos de dados e gráficos dos jogos

## 🔄 Atualização Automática

Este branch é atualizado automaticamente pelo workflow GitHub Actions sempre que:
- Novas predições são geradas
- Análises estatísticas são atualizadas  
- Gráficos de benchmark são regenerados
